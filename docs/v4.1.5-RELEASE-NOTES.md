# PF-Player v4.1.5 发布说明

## 📋 版本信息
- **版本号**: v4.1.5
- **发布日期**: 2026-06-06
- **更新类型**: UI优化与功能完善

---

## ✨ 更新内容

### 1. 悬浮播放条优化
- 统一了右侧按钮尺寸（喜欢、播放/暂停、播放列表）
- 移除了圆形外轮廓，仅保留简洁SVG图标
- 优化了按钮的hover效果
- 修复了播放/暂停图标切换问题

### 2. 播放列表功能完善
- 播放页底部播放列表按钮现在可以正常显示弹窗
- 在"正在播放"列表中高亮显示当前播放曲目
- 正在播放的曲目显示▶图标和" - 正在播放"标记
- 移除了Tab的背景色，界面更简洁

### 3. 歌词显示优化
- 播放页歌词容器固定高度为40px，仅显示单行歌词
- 实现了长歌词的横向滚动效果
- 歌词滚动使用缓动函数，更加平滑
- 歌词和提示词现在完全居中显示
- 播放页中央歌词和歌词页实现了同步滚动

### 4. 歌词页提示优化
- 提示文案从"← 右滑返回播放界面"改为"左滑返回>>"
- 添加了呼吸动画效果（2秒循环）
- 实现了3秒后自动隐藏提示的功能
- 隐藏过程使用淡出动画（1秒过渡）

### 5. 版本号统一
- 所有位置的版本号统一更新为v4.1.5
- 包含：加载页面、package.json、manifest.json、app.js、设置页面
